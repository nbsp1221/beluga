# Beluga 제품 방향

Beluga는 대화와 도구를 같은 작업 공간에서 사용하는 독립 에이전트 하네스 제품이다. DSH의 플러그인 소유권과 작업 공간 구성에서 배우되 DSH에 플러그인을 붙이는 배포판으로 만들지 않는다. [결정 이유](decisions/0001-independent-plugin-product.md)를 따른다.

## 사용 맥락과 원칙

워크스페이스별로 대화를 만들고 같은 작업의 메시지와 실행 기록을 확인하는 단일 사용자를 지원한다. 에이전트는 사용자가 선택한 Host에서 실행한다. 원격 브라우저와 Windows 데스크톱의 연결 방식은 [Host 운영 문서](hosting.md)를 따른다.

- 채팅에 갇히지 않는 작업 공간: 전역 목적지, 목적지별 탐색, 중앙 작업 화면, 선택적 문맥 패널을 구분한다.
- 확장 가능한 기능: 기능은 명시적인 서비스와 화면 등록으로 조립하고 종료 시 소유 자원을 해제한다. 모든 버튼을 플러그인으로 만들지는 않는다.
- 커스텀하기 쉬운 기반: Turborepo 모노레포, Tailwind와 shadcn을 사용하고 공식 기능과 공통 규칙을 우선한다.
- 익숙하고 일관된 화면: DSH의 구조와 Codex의 좌측 전역 탐색을 참고한다. 정확한 현재 규칙은 [디자인 시스템](design-system.md)이 소유하며 픽셀 복제를 목표로 삼지 않는다.
- 정직한 동작: 제품 이름은 Beluga다. 구현 상태를 설명하는 불필요한 문구는 제품 화면에서 제거하되 없는 엔진·도구 실행을 꾸며내지 않는다.

## 제공 범위

Host에 접속 코드로 로그인한 뒤 모델을 연결하고, 등록한 워크스페이스에서 텍스트 대화를 시작한다. Chat에서 응답과 도구 활동을 보고, Trajectory에서 모델 요청과 도구 호출을 검사한다. 파일 도구는 Host에서 실행된다. 파일 패널과 메시지 첨부의 범위는 [아키텍처](architecture.md)에서 관리한다.

재사용 가능한 에이전트 구성의 제품 용어는 **Agent preset(에이전트 프리셋)**이다. 처음에는 코드 조사·수정·검증을 위한 **Standard**를 제공한다. 사용자는 지침과 기능을 조합해 새 프리셋을 만들 수 있다. 대화 헤더의 **Agent**는 해당 대화가 사용하는 프리셋을 보여준다. 프리셋, 세션, 실행 정책의 경계는 [에이전트 프리셋과 실행](architecture.md#에이전트-프리셋과-실행)에 둔다.

## 현재 비목표

DSH 소스 포크, 자체 모델 실행 루프 재작성, 범용 도킹/레이아웃 DSL, 외부 플러그인 마켓플레이스, 동적 설치·핫스왑, 별도 모바일 앱/디자인 시스템은 현재 범위가 아니다. 기능 요구가 생길 때 대안을 검토한다.

Plugins·Automation 자리 표시자를 실제 기능으로 확장할지와 언제 구현할지는 미정이다. 기존 표시만으로 해당 화면이나 기능 추가가 승인된 것으로 보지 않는다. 참고 이미지의 색·아바타·통화 기능도 자동으로 요구사항에 포함하지 않는다.

제품 원칙·비목표가 바뀔 때 이 문서를 검토한다. 참고 코드는 제품 구현으로 복제하지 않으며 [제3자 고지](../THIRD_PARTY_NOTICES.md)를 유지한다.
